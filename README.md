# Streamlit ai_dashboard

Проект создан как небольшое приложение для проверки бизнес-гипотез, с расчётом на низкую нагрузку, собранные данные хранятся в БД на SQLite, и рассчитаны на небольшой поток данных. 

Цель данной работы заключается в представлении MVP, наброска, на основе которого можно развивать полноценное приложение с применением ИИ компонента для упрощения и автоматизации работы аналитика. В этой работе также практикуются следующие навыки:
	Интеграции ИИ сервиса для целей аналитики
	Работа с окружениями и терминалом
	Развёртывание демонострационного приложения на облачном сервисе Streamlit

## Стек технологий 
- ИИ Агент: Google Gemini API 
- База данных: SQLite 
- Язык и библиотеки: Python (Streamlit, Pandas, JSON) 
- Среда разработки: Jupyter Notebook

## Реализованы следующие процессы работы:
	Написание приложения app.py, в котором прописывается логика работы БД - его структура, функции для инициализации, сохранения отзывов, выгрузки данных для элементов дашборда. 
	Подготовил функцию для написания запроса к Gemini для получения ответа в формате json и последующего парсинга.
	Задал следующие элементы страницы - форма для написания отзыва, Дашборд элементы - диаграмма, таблица.

Подготовлен app.py, папка проекта выгружена на облачный сервис streamlit.app.
